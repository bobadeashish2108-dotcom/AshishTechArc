# AshishTechArc

A free, responsive personal portfolio website for Ashish Bobade, Salesforce Consultant.

## Included pages
- Home
- About
- Videos
- Blog
- Projects
- Contact
- Resume

## Before publishing
1. Replace the `AB` profile placeholder with your photo if desired.
2. Add your real project details.
3. Add your YouTube/video links.
4. Add your blog article links/content.
5. Add a real email/contact form service if you want form submissions.

## Free hosting with GitHub Pages
1. Create a free GitHub account.
2. Create a new public repository named `ashishtecharc` (or any name).
3. Upload all files and folders from this project.
4. In GitHub, open **Settings → Pages**.
5. Select **Deploy from a branch**, choose `main`, folder `/ (root)`, and save.
6. GitHub will give you a free address such as `https://yourusername.github.io/ashishtecharc/`.

A custom `.com` domain is optional and normally costs money. The hosting itself can remain free.
